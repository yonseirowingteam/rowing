슬라이드 11~12복습 퀴즈: Cottrell 식이란? (00:00~04:38)

🗣 수업은 학생들에게 던진 질문으로 시작합니다. "Cottrell 식이란 무엇인가?" 학생들이 "전류를 시간의 함수로 나타낸 식"이라고 답하자 교수님은 그것만으로는 충분하지 않다고 하십니다 (01:52).

⚠️ Cottrell 식이 되려면 추가 조건이 있다: 가해 준 전위가 충분히 높아서(=충분히 환원쪽으로 가서) 표면 농도가 0이 되어야 한다. 이것이 경계조건 CO(0,t)=0 (t>0)입니다.
  1. 전위를 가하면 표면 농도가 계속 줄다가 0에 도달합니다.
  2. 그 뒤 농도구배는 확산층이 두꺼워지면서 서서히 감소 → 이런 전류 응답이 Cottrell 식에 해당합니다.
  3. 그림의 계단 4와 5는 전류 응답이 똑같습니다. 이유(03:12): 계단 4에서 이미 표면농도가 0에 도달했기 때문. 표면농도가 0이 된 뒤에는 더 높은 전위를 가해도 농도구배가 같고, 확산층 두께는 시간 t만의 함수이기 때문입니다.
🗣 03:39 핵심 정리
"Cottrell 식 아래에서는 어느 지점 이후 전위를 얼마나 가하든 전류 응답이 항상 같다. 그 지점의 전위가 표면농도가 0인 전위다."

슬라이드 12두 식의 차이: 직선 vs 곡선 (05:20~07:54)

🗣 전류 응답을 구한 식이 두 가지 모양입니다: ① 선형 구배를 가정한 식 i_c = nFADo1/2[C*−C(0)]/(2t1/2) ② 실제 Cottrell 식 i = nFAD1/2C*/(π1/2t1/2). 무엇이 이 차이를 만들까요? 학생 답 "곡선(curved)" → 맞습니다 (06:09).

  • ①은 농도구배가 직선이라고 가정한 근사.
  • ②는 실제로는 구배가 곡선이라는 현실을 반영 → 더 정확.
  • 확산층 두께도 마찬가지: 가정으로는 2√(Dt), Cottrell에서 구하면 6√(Dt) (erf(3)≈1 사용). 6쪽이 훨씬 큰 이유도 구배가 곡선이기 때문입니다 (06:58).

슬라이드 9RHE를 쓰는 이유 (07:54~09:45)

🗣 "pH 보정이 쉬워서"입니다. 실험에서 어떤 pH를 썼든 모든 전위를 RHE로 변환하면 사용한 용액의 pH를 다시 따질 필요가 없습니다. (ERHE=Eref+E°ref+0.059·pH)

슬라이드 12potential step으로 얻는 정보 (09:45~14:17)

🗣 "결국 potential step으로 어떤 정보를 얻나?" 답: 확산계수(D)와 벌크 농도. 학생이 말한 것처럼 전해질에 녹아 있는 종의 농도를 측정할 수 있습니다. 또 Anson plot에서는 이중층 용량(전하) 정보도 얻습니다.

슬라이드 12Anson plot (14:17~17:30)

  1. 전위 계단 실험에서 총 전류 = 패러데이 전류(산화환원) + 비패러데이 전류(이중층 충전). 비패러데이 전류는 항상 패러데이 전류보다 먼저 흐릅니다 (14:52).
  2. 총 전하 Q = Qf + Qdl (dl = double layer).
  3. 패러데이 전하 = 확산전류 i_d의 시간적분 (질량전달 제어 전류, 확산에 의한 전류). 이중층 쪽은 Qdl.
  4. 전류가 t의 함수이므로 대입·적분(0→t) →
Q = [ 2nFA·DO1/2·C*O / √π ] · t1/2 + Qdl
  1. Q vs t1/2를 그리면 직선. 기울기 → 확산계수 D (그리고 농도), y절편 → Qdl(이중층 전하). 이 그래프가 Anson plot.

슬라이드 13왜 마이크로전극인가 (17:30~21:16)

🗣 마이크로전극 = 전해질에 노출된 전극 면적이 아주 작은 전극.

  • 충전 시간 문제: 전위 계단 후 비패러데이 전류가 이중층을 먼저 충전하고, 충전이 끝나야 비로소 진짜 패러데이 전류를 측정할 수 있음.
  • 충전이 너무 오래 걸리면 자연대류가 생겨 농도구배가 왜곡됨. 자연대류 = 밀도 차에 의한 대류(차가운 유체는 내려가고 뜨거운 것은 올라감, 시간이 지나면 발생). 구배가 왜곡되면 if 측정이 어려워짐.
  • 그래서 실험 전체를 10~20초로 제한. 충전에 10초 걸리면 패러데이 전류는 10초 후부터 → 남는 건 10초 → Anson plot의 선형 구간이 너무 짧아 신뢰할 만한 기울기를 얻기 어렵고 D의 신뢰도가 낮음.
⚠️ 해결책 = 시간상수 τ를 줄인다. τ = Rs·Cdl (커패시터에서 배운 시간상수). τ가 크면 충전이 느림. Cdl ∝ 전극 면적 → 면적을 줄이면 Cdl↓, τ↓ → 충전이 빨리 끝나고 Anson plot의 선형 구간이 길어져 더 믿을 만한 데이터. (20:31)

슬라이드 14구형 확산 (21:16~24:31)

🗣 마이크로전극에서는 직각좌표계를 쓸 수 없습니다. 전극이 매우 작으면 확산이 사방으로 퍼지는 구형(spherical) 확산이기 때문. 그래서 좌표계만 직각 → 구좌표로 바꿔 푼 것이고 나머지는 모두 같습니다. 변환 과정은 보여주지 않으시고 결과 식만:

id(t) = nFADOC*O [ 1/(πDOt)1/2 + 1/r₀ ] t→∞ : id = nFADOC*O / r₀

t→∞이면 첫 항이 0 → 남는 항이 정상상태(steady-state) 전류. r₀는 마이크로전극의 반지름(내가 아는 값). 같은 실험을 마이크로전극으로 하고 정상상태 전류를 재면 확산계수와 벌크 농도를 정확히 알 수 있습니다.

슬라이드 15LSV와 가정 (24:31~27:23)

🗣 LSV는 가장 자주 쓰는 전기화학 실험. 전위를 초기값에서 최종값까지 선형으로 쓸어(sweep) 전류를 측정. E = Ei − νt. ν = 주사속도(예: 10 mV/s, 100 mV/s 등 내가 정함), 초기 전위도 내가 정함.

가정이유 (교수님 설명)
교반 없음(대류 무시)대류 항 제거
지지전해질 과량migration(이동) 기여 제거
작은 전극 → 벌크 농도 일정큰 전극은 많은 종을 소모해 벌크 농도 자체가 변함. 그래서 면적이 비교적 작은 전극
확산만으로 물질전달위 조건들의 결과

산화종 O가 전자를 받아 R이 되는 환원: 전위가 더 음(−)이 될수록 환원 진행. 표면(x=0) 농도 CO(0,t)는 Nernst 식이 정함 (Nernstian 계). 확산층은 시간에 따라 증가(선형 관계의 구배).

슬라이드 15~16LSV 전류 응답 모양 (27:23~32:18)

⚠️ "전류는 처음에 농도구배가 커지면서 증가하다가, 고갈(depletion) 때문에 감소한다. 이걸 꼭 기억하세요." potential step은 전위를 가하는 처음이 최대이고 계속 감소하지만, LSV는 전위를 바꾸므로 서서히 증가 → 최대 → 감소. (27:49)

점 a~e를 그래프 작도 탭의 애니메이션에서 직접 보세요. 설명 요약: 모든 전류는 농도구배로 설명됩니다. 확산층 두께는 시간만의 함수로 계속 늘어납니다.

  • a: 초기 전위가 onset 전위보다 낮아 패러데이 전류 없음.
  • b: 전위가 오르면 (물질전달 제어이므로) 전위가 곧 표면농도·구배를 결정 → 전류 증가.
  • c: 구배 더 증가 → 전류 계속 증가 (c는 E½ 부근).
  • d: 구배 최고 → 피크.
  • e: 표면농도가 0이 된 뒤 구배는 점점 감소 → 이후는 Cottrell 거동.
🗣 32:18 시험 포인트
"최대 농도구배는 표면농도가 0이 되는 점에서 나타나는 게 아니다. 그보다 앞(피크 부근)에서 최대 구배가 관찰된다." (피크 시점의 표면농도는 0이 아님 → 작도 애니메이션에서 확인)

슬라이드 16Epc, E½, ipc 정의 (32:18~37:39)

  • ipc: 피크 전류, 그때의 전위 Epc(cathodic peak potential). ipc의 절반 전류에 해당하는 전위가 Epc/2.
  • 피크와 반파전위 차: Epc − E1/2 = −1.109RT/nF = −28.5/n mV (25℃). 유도는 안 보여주심 — "이 수준에선 안 해도 됨, 결과만 알면 된다."
  • 반파전위: E1/2 = E°′ + (RT/nF)·ln(DR/DO). 대부분 DR≈DO → ln항=0 → E½ ≈ E°′ (formal potential).
  • ⚠️ formal potential에서 반응물과 생성물의 농도가 같다. (학생에게 질문 후 정답 확인, 35:18) → 그림의 점 c가 농도의 중간 지점.
  • Epc와 Epc/2의 전체 차는 약 56.5/n mV (28/n + 28.5/n의 합).
  • Randles–Ševčík: ipc = 0.4463(F³/RT)1/2n³ᐟ²AD1/2C*v1/2 = (2.69×10⁵)n³ᐟ²AD1/2C*v1/2 (25℃, 상수 대입). 외울 것: ipc ∝ 벌크농도 C*, 주사속도의 제곱근 v1/2.

슬라이드 17주사속도 효과와 비패러데이 전류 (37:39~43:30)

🗣 주사속도 1→5로 높이면 전류 곡선이 커집니다. "왜 그런지 쉽게 설명할 수 있다"고 하셨는데, 해당 설명 구간(38~41분)이 대본에 빠져 있습니다. (제 보충: 빠르게 쓸면 확산층이 자랄 시간이 짧아 구배가 가팔라 전류↑ → ipc ∝ v1/2)

⚠️ 비패러데이 전류 줄이는 법 (41:59~43:30)
inf/ipc = Cdl·v1/2 / [ (2.69×10⁵)n³ᐟ²D1/2C* ] 이 비가 0에 가까우면 비패러데이 기여를 무시할 수 있음. 방법: ① 벌크 농도↑ (불가능하면 ②) ② 주사속도↓.
주사속도를 높이면 inf가 커지는 이유: Cdl을 전위 sweep법으로 재던 것을 떠올리세요. inf = Cdl·v (v에 비례)인데 ipc는 v1/2에 비례하므로 비는 v1/2에 비례. (분모에는 v1/2, 분자에는 v가 있어 약분되어 v1/2이 남는다는 설명)

A. LSV 전류 응답(i–E)을 그리는 순서

아래는 확산 방정식을 실제로 수치 계산한 시뮬레이션입니다(Nernst 경계조건, 가역계). ▶ 재생하거나 슬라이더를 움직이거나 a~e 버튼을 눌러 보세요. 왼쪽 = 전극 표면 근처 농도 분포(C/C*), 오른쪽 = 지금까지 그려진 i–E 곡선.

그리는 순서 (손으로 그릴 때)

  1. x축 = 전위 E (오른쪽으로 갈수록 더 음(−), 슬라이드 16 표기 E(−)), y축 = 환원전류 ic. 시작점 Ei(a)에서 전류 0.
  2. a→b→c: 천천히 상승. E½(≈E°′)는 c 근처, 이때 [O]=[R].
  3. d에서 피크 (Epc, ipc). Epc는 E½보다 28.5/n mV 더 음.
  4. d→e: 표면농도가 0에 도달한 뒤 Cottrell 형태(t−1/2)로 감소. 점선으로 기저선 상상하면 쉬움.
  5. 표시: Epc, E1/2, ipc, 0.5 ipc와 Epc/2.

B. Anson plot (Q vs t1/2) 그리는 순서

  1. x축 t1/2, y축 총전하 Q.
  2. y절편 = Qdl (이중층 충전 전하) — 원점이 아님! 직선이 y축을 양(+)의 값에서 자름.
  3. 직선 기울기 = 2nFAD1/2C*/√π → D 또는 C*를 구함.
  4. ⚠️ 이중층 충전이 길면(τ 큼) 초반이 휘어서 직선 구간이 짧아짐 → 마이크로전극으로 τ를 줄임.
